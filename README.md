# Разновидности существительных III склонения

Учебный проект по латинскому языку для медицинского вуза. Вводишь существительное в Nom. Sing., программа находит его в словаре (пособия Бондаренко и Чернявского) и пошагово определяет разновидность: гласную, смешанную А, смешанную Б или согласную.

Открыть: `index.html` (или `Латынь_III_склонение.html`, это тот же файл) — работает в любом браузере без интернета.

Исходники лежат в `src/`: `logic.js` (алгоритм), `nouns.js` (словарь), `template.html` (интерфейс). После правок собрать заново:

```
node src/build.js
```
